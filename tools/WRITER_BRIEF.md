# 記事本文 執筆ブリーフ（packing-list.net）

## サイトの性格
「旅行持ち物リストメーカー」（https://packing-list.net/）のSEO記事。
トップページは行き先と泊数を入れると持ち物リストが自動生成される無料ツール。
記事は検索流入を取り、最後にツールへ誘導する役割。

## 出力するファイル（2つ）
作業ディレクトリ: このブリーフと同じフォルダ
1. `body_<slug>.html` … 記事本文のHTMLフラグメント（後述）
2. `faq_<slug>.json`  … メタ情報のJSON（後述）

## body_<slug>.html の仕様
- `<h1>` / `<head>` / `<header>` / `<footer>` / CTAバナー / シェアボタン / 関連記事欄は **書かない**
  （ビルドスクリプトが自動で付ける）。書くのは h1 の直後から CTA の直前まで。
- インデントは半角スペース6個から始める（`      <p>…`）。
- 先頭は必ず導入文: `      <p class="intro">…</p>`（180〜260字。読者の悩みと記事で分かることを書く）
- 見出しは `<h2>` と `<h3>` のみ。`<h1>` は使わない。h2 は 6〜9個、各 h2 の下に h3 を 2〜5個。
- 最後の h2 は必ず `<h2>よくある質問</h2>` にして、その下に h3（質問文）+ p（回答）を **3〜4組**。
  質問の h3 には「？」を付けない（例: `<h3>子どもの分の薬はどう用意しますか</h3>`）。
- 使えるクラスは以下だけ。独自のstyle属性やclassは追加しない。
  - 強調ボックス: `<div class="highlight-box"><strong>見出し</strong><br>本文</div>`
  - チェックリスト: `<div class="checklist"><ul><li>項目</li>…</ul></div>`
  - 比較表: `<table class="comparison-table"><thead><tr><th>…</th></tr></thead><tbody><tr><td>…</td></tr></tbody></table>`
- highlight-box は 2〜3個、checklist は 3〜6個、comparison-table は 1〜3個を目安に配置する。
- 内部リンクを **本文中に 5〜8本** 自然に入れる。形式は `<a href="./<slug>.html">記事名や自然な語句</a>`。
  リンク先は LINKS_existing.md と LINKS_new.md に載っているものだけ。存在しないslugは絶対に書かない。
  同じリンク先を2回以上使わない。「こちら」だけのアンカーテキストは禁止。
- 外部リンクを張る場合は `<a href="URL" target="_blank" rel="noopener">…</a>`。
  外部リンクは FACTS.md に出典として載っている公式URLのみ許可（各記事0〜3本）。

## 分量
本文（HTMLタグを除いた日本語の文字数）で **7,000〜9,400字**。7,000字を下回らないこと。
書き終えたら自分で概算し、足りなければ加筆する。

## 文体・トーン
- です・ます調。落ち着いた実務的な文章。煽らない。
- **絵文字は一切使わない**（記号としての「※」「〜」は可）。
- 「！」を多用しない。1記事あたり0〜2個まで。
- 一人称や運営者の個人的な身元に触れない。「編集部」「筆者」も出さない。
- 体験談を装った創作をしない。「〜という声が多い」「〜になりがちです」など一般論として書く。
- 断定できない事柄は「〜の場合が多い」「〜が目安です」と幅を持たせる。

## ファクトチェック（最重要）
- **FACTS.md に書かれていない法令・規則・手数料・数値を書かない。**
  FACTS.md にある事項は、そこに書かれた表現・数値のとおりに書く（勝手に丸めない・言い換えて意味を変えない）。
- 制度や料金に触れる必要があるが FACTS.md に無い場合は、金額や条件を断定せず
  「渡航前に公式サイトで最新の情報を確認してください」と誘導する。
- 商品名・ブランド名の具体的なスペック（容量・価格・型番）は書かない。カテゴリ名で書く。
  例: ×「Anker の 10000mAh」→ ○「1万mAh前後のモバイルバッテリー」
- 気温・気候は「おおむね」「平年並みで」など幅のある表現にし、断定的な数値の羅列は避ける。
  月別の傾向を語る程度に留め、細かい平年値の表は作らない。
- 為替レート・物価の具体的な金額は書かない。
- 医療・健康に関する記述は一般的な注意にとどめ、診断や治療の助言はしない。
  必要に応じて「医師に相談してください」と書く。

## faq_<slug>.json の仕様
UTF-8。次の形（本文の「よくある質問」から2つを選んで転記する。回答は80〜160字に要約可）:
```json
{
  "description": "検索結果に出るメタディスクリプション。90〜120字。記事の要点を具体的に。",
  "faq": [
    {"q": "質問文（？を付ける）", "a": "回答文"},
    {"q": "質問文（？を付ける）", "a": "回答文"}
  ],
  "cta_title": "CTAバナーの見出し（15〜25字）",
  "cta_text": "CTAバナーの本文（40〜60字）。ツールで持ち物リストが作れることを伝える。"
}
```

## 禁止事項チェック（提出前に自己確認）
- [ ] 絵文字が入っていない
- [ ] 存在しない slug へのリンクが無い
- [ ] FACTS.md に無い法令・手数料の数値を書いていない
- [ ] 本文が7,000字以上ある
- [ ] `<h1>` を使っていない / CTAバナー・関連記事欄を自分で書いていない
- [ ] JSONが正しくパースできる
